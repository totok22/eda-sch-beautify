# 原理图美化导出

给嘉立创 EDA 专业版导出的原理图 SVG、PNG 做美化。只处理导出的图片，不改原理图本身。

## 能做什么

- 不相连的导线交叉处加半圆跨线弧。水平线向上鼓起。相邻的交叉会等大缩小，或者合并成一段。弧线避开节点、引脚和文字。
- 节点圆点改成所在导线的颜色。
- 删掉灰色的未连接标记。
- 中文用宋体，英文保持 Times New Roman。同一行里的中英文会分开设置。
- 去掉导出文件自带的整页背景。
- PNG 可选 1x、2x 和 4x。背景可选透明、白色或纸色 `#F5F4EF`。
- 可以导出整页、选中图元，或手动框选的区域。

## 怎么用

先打开原理图编辑器里的一个图页。顶部菜单选择“原理图美化”。

- “快速导出美化 SVG（整页）”：导出当前图页，处理后保存为 SVG。
- “导出面板（PNG / 区域 / 设置）…”：打开面板。在面板里选 PNG 或 SVG、倍率、背景、配色和导出范围。
- “关于…”：查看版本。

从扩展广场安装后，打开扩展管理器的“已安装”。启用本扩展，并勾选“显示在顶部菜单”。勾选之后，原理图编辑器顶部才会出现“原理图美化”。

多图页导出如果得到的是压缩包，请改到单个图页里再导出。

## 面板

![面板（浅色）](images/panel_light.png)

![面板（深色）](images/panel_dark.png)

面板跟随 EDA 当前的深色或浅色主题。预览可以用滚轮缩放，也可以用 +、−、适应和 100%。按住空格、按住中键，或打开平移模式，可以拖动预览。

PNG 会先按目标像素尺寸栅格化，背景铺满整张画布。透明模式导出的是真透明。

导出配色有三项：默认、白底黑线和黑底白线。

## 限制

- 只处理水平和竖直导线。斜线会跳过。轻微偏斜的导线按正交导线处理。
- 文字避让用的范围按字号估算。
- “选中图元”要求 EDA 图元 ID 和 SVG 元素 ID 对得上。对不上时改用坐标换算。这时可以改用手动框选。
