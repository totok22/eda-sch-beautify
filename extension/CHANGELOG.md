# 更新日志

## 0.3.2
- 导出文件命名改为 `<图页名>_<YYYYMMDD-HHmm>[@Nx].<扩展名>`，如 `电源模块_20261017-1532.svg`、`电源模块_20261017-1532@4x.png`（1x 不带倍率后缀；不再有 `_beautify`）。图页名取自 `dmt_Schematic.getCurrentSchematicPageInfo()`，时间为本机本地时间、精确到分钟；非法字符（`\ / : * ? " < > |` 及控制字符）换成 `_`，超过 80 个字符截断；接口取不到时退回 EDA 导出文件名，再退回 `schematic`
- 面板和“快速导出 SVG”共用同一套命名（`src/file-name.ts`），并补了命名相关的回归测试；测试运行器支持异步用例

## 0.3.1
- 预览性能与清晰度：预览改为栅格位图（全页底图最长边 ≤2048、DPR 封顶 2），缩放/平移只改一层 `transform`；操作停下后再按“当前缩放 × DPR”重绘可视区细节层，放大后依然清晰。无头 Chrome 在 2.3 MB 的拼接大图上实测：滚轮缩放最长一帧约 466 ms → 17 ms，框选拖动每次 mousemove 的 JS 开销降到约 1/40（EDA 内置浏览器未单独实测）
- 去掉主题轮询（改为系统主题变化 / 面板重新获得焦点时检查）；去掉悬浮工具条的 `backdrop-filter` 和大图层的 `box-shadow`
- 只改背景底色 / PNG 倍率 / 边距时不再重跑美化算法；滚轮缩放改为指数缩放（触控板不再一下放大很多）；窗口尺寸变化时保留用户的缩放与平移；“适应”会避开悬浮工具条；导出区域框恒为 2px，选中图元模式下框住的是含边距后的真实导出范围
- 修复“黑底白线”画不出黑底：新增“纯黑”背景，选择“黑底白线”时自动切换，离开时换回纸色
- 修复配色转换破坏 `<mask>` / `<pattern>` 内的白色和 `url(...)` 填充（会让图案填充消失）
- 修复底板识别误删用户画的分组框 / 模块框：只删无描边的浅色大底板、整页底板和带 sheet/frame/background/page 标记的矩形
- 修复 `applyBackground` 在 `</defs>` 靠后时把背景盖到内容上面；背景现在总是根元素的第一个子元素
- Python 命令行同步底板识别规则，并新增 `--color-theme default|black-on-white|white-on-black`
- 新增 `npm run test`（`extension/test/test-core.ts`），`.eext` 不再打入 `.DS_Store`
- 开发者信息（`publisher` / 作者 / LICENSE 版权人）统一为 totok22

## 0.3.0
- 改名为「原理图美化导出」（eda-sch-beautify）
- 面板支持深色/浅色主题（跟随 EDA 主题，`sys_Window.getCurrentTheme`）
- 预览支持滚轮缩放、+/−、适应、100%，空格/中键/平移模式拖动
- PNG：SVG 先按目标像素尺寸栅格化，背景铺满整张画布；透明模式真透明；自动移除导出自带的整页背景
- 新增「导出配色」选项（默认 / 白底黑线 / 黑底白线）
