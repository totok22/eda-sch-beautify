# 更新日志

## 0.3.0
- 改名为「原理图美化导出」（eda-sch-beautify）
- 面板支持深色/浅色主题（跟随 EDA 主题，`sys_Window.getCurrentTheme`）
- 预览支持滚轮缩放、+/−、适应、100%，空格/中键/平移模式拖动
- PNG：SVG 先按目标像素尺寸栅格化，背景铺满整张画布；透明模式真透明；自动移除导出自带的整页背景
- 新增「导出配色」选项（默认 / 白底黑线 / 黑底白线）

## 0.2.0
- PNG 改在 IFrame 面板中渲染（修复 `URL.createObjectURL` 不可用）
- PNG 倍率 1x/2x/4x，背景 透明/白/KiCad 纸色 #F5F4EF
- 导出范围：整页 / 选中图元 / 手动框选
- 中英文混排：中文宋体、英文 Times New Roman（split 模式）

## 0.1.0
- 首个版本：跨线弧、节点改色、删除未连接标记、中文改宋体，导出 SVG
